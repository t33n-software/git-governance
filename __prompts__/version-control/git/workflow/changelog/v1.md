## 3. Detailed Version Entries
[INTENT: SPECIFICATION]

### 3.1 Version `1.5.0`
[INTENT: SPECIFICATION]

Required task worktrees across the hotfix and release lanes: the eight local
working-branch dispatches fail closed outside a linked task worktree, the
shared lane-aware guard measures each lane's own acquisition base, and the
workflow core binds the same requirement and lane base. Full classification,
change units, migration impact, and commit alignment live in
`changelog/v1/v1-5-0.md`.

### 3.2 Version `1.4.0`
[INTENT: SPECIFICATION]

Modularized the adapter metadata surfaces: the changelog descended into the
semver-owned family TOC with exactly one concrete version leaf per released
version, the description descended into the kebab-case detail package, and
the core metadata pair was aligned with the merged worktree lifecycle. Full
classification, change units, migration impact, and commit alignment live in
`changelog/v1/v1-4-0.md`.

### 3.3 Version `1.3.0`
[INTENT: SPECIFICATION]

Bound the task-bound worktree convention across the workflow contracts: the
actor-agnostic worktree rule, the worktree lifecycle endpoint register, the
publish-return special case, and the merged legacy-name generalization. Full
classification, change units, migration impact, and commit alignment live in
`changelog/v1/v1-3-0.md`.

### 3.4 Version `1.2.0`
[INTENT: SPECIFICATION]

Hardened the adapter into a fully gated DWCEA bootstrap: binding activation
contract, fine-grained state machine, explicit proof ledger, pre-action
embargo, invalidation rules, bootstrap symbol discipline and an extended
prohibition and completion contract. Full classification, change units,
migration impact, and commit alignment live in `changelog/v1/v1-2-0.md`.

### 3.5 Version `1.1.0`
[INTENT: SPECIFICATION]

Split the portable binary workflow core from this repository's Go-source
adapter; added complete adapter and core metadata plus Help-first drift
controls. Full classification, change units, consumer impact, and commit
alignment live in `changelog/v1/v1-1-0.md`.

### 3.6 Version `1.0.0`
[INTENT: SPECIFICATION]

Canonicalized the governed workflow prompt and retained the stable Cursor
rule entrypoint. Full description and commit alignment live in
`changelog/v1/v1-0-0.md`.
