**Classification**

| Field | Value |

| Semver Class | `minor` |
| Breaking Change | `no` for the complete workflow bundle |
| Rationale | The change is a backward-compatible projection of the core anchor contract into the repository-local binding: the adapter still replaces only the executable prefix, still derives every flag from current help, and still forbids skipping the help of any endpoint that carries a state effect or starts a lane; the new sentences only state explicitly that the repository-local execution inherits the core epoch economy for read-only idempotent endpoints and that the existing [1.5] invalidation list is what closes an epoch.
