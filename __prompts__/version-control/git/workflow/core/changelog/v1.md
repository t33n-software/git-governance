## 3. Detailed Version Entries
[INTENT: SPECIFICATION]

### 3.1 Version `1.2.0`
[INTENT: SPECIFICATION]

Registered the governed conflict resume for the standalone `branch sync-base`
path: the registry row binds the deliberate isolated base synchronization and
the governed re-entry into its conflict-paused rebase or merge operation, and
the conflict protocol binds the concrete governed resume entry points. Full
classification, change units, migration impact, and commit alignment live in
`changelog/v1/v1-2-0.md`.

### 3.2 Version `1.1.0`
[INTENT: SPECIFICATION]

Additive hardening of the core across guards, task patterns, execution levels,
state and proof surfaces, registry coverage, status symbols, ticket discovery,
and provider-session prefetch. Full classification, change units, migration
impact, and commit alignment live in `changelog/v1/v1-1-0.md`.

### 3.3 Version `1.0.0`
[INTENT: SPECIFICATION]

units, migration impact, and commit alignment live in
`changelog/v1/v1-0-0.md`.
