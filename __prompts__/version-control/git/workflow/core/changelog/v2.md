## 3. Detailed Version Entries
[INTENT: SPECIFICATION]

### 3.1 Version `2.0.0`
[INTENT: SPECIFICATION]

Bound the file-based message transport: multi-line message parts (commit
bodies and pull-request descriptions) cross the CLI boundary exclusively
through message files passed by absolute path — an existing plain UTF-8 text
file of at most 1 MiB whose content is carried verbatim — the string body and
message flags are withdrawn, the temp-file creation discipline is owned by
the core as contract section [6.4.6], and the prohibition list excludes the
temp area as an information source. Full classification, change units,
migration impact, and commit alignment live in `changelog/v2/v2-0-0.md`.
