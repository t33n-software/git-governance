### 3.1 Version `1.8.0`
[INTENT: SPECIFICATION]

**Classification**

|| Field | Value |
||-------|-------|
|| Semver Class | `minor` |
|| Breaking Change | `no` |
|| Rationale | The change is an additive endpoint-map row, an evidence-basis replacement inside the existing proactive discovery, an audit-record field extension, and coherence wording. **Migration / Consumer Impact**

No migration required. Consuming agents and adapters read the same core
prompt; the registered capability activates through the existing help-first
runtime contract, and an installed binary that predates the endpoint simply
offers no such help entry, which keeps the reference truthful on older
installations while the P2/P3 fallback levels remain valid.
